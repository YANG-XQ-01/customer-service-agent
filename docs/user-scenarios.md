# 用户消息测试样本（阶段 0 小任务）

> 这是给你的动手练习：把平时真实客服会遇到的话写下来，并标注你认为该走哪个分支。
> 答案没有标准，阶段 2~4 会拿这些样本当演示和验收素材，届时可以对照真实行为修正。

| # | 用户消息 | 我猜的意图（分支） | 备注（期望系统做什么） |
|---|---|---|---|
| 1 | 帮我查一下订单 20260901001 到哪了 | 订单查询 | 查出订单号和物流状态 |
| 2 | 这件商品七天无理由退货吗 | 知识问答 | 去政策库检索并回答 |
| 3 | 我要退掉上个月买的那个键盘 | 售后 | 找售后单/订单，走退货流程 |
| 4 | 在吗 | 闲聊 | 正常寒暄，不进业务分支 |
| 5 | 你们这是诈骗，我要投诉 | 转人工 | 安抚并转人工，带上对话上下文 |

请至少补充到 10 条，覆盖：订单查询、物流、退货、退款、商品咨询、售后政策、闲聊、投诉/转人工，以及你觉得会难住机器人的刁钻问题。
